參加指定活動

設定邏輯說明：下方「判斷條件類型」＋「門檻模式」可自由組合，共支援以下情境：

  1. 品名比對 → 合計金額大於 0 即可抽獎/給獎
  2. 數量＋單一門檻 → 依數量抽獎/給獎
  3. 數量＋多重門檻・系統自動擇優 → 依購買數量落點判斷抽獎/給獎
  4. 數量＋多重門檻・分開建活動並互斥 → 玩家同時符合多個數量門檻時僅能擇一參加抽獎/給獎
  5. 金額＋單一門檻 → 依金額抽獎/給獎
  6. 金額＋多重門檻・系統自動擇優 → 依購買金額落點判斷抽獎/給獎
  7. 金額＋多重門檻・分開建活動並互斥 → 玩家同時符合多個金額門檻時僅能擇一參加抽獎/給獎
